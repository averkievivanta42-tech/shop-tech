# Сайт-каталог з кошиком на Vue.js 3

## Тема проєкту
**МегаТренд - магазин техніки** - сучасний інтернет-магазин комп'ютерної техніки, смартфонів, планшетів, моніторів, аудіо, смарт-годинників, периферії та аксесуарів.

---

## Реалізований функціонал

### Обов'язкові вимоги:
1. **Каталог товарів (38 позицій):** кожен товар має назву, артикул (`MT-...`), бренд, ціну, стару ціну, галерею реальних зображень у кількох ракурсах (3-5 фото), категорію, розширений опис, детальну таблицю технічних характеристик (13-20 параметрів), структуровані атрибути фільтрації, рейтинг, відгуки покупців та статус наявності. Дані зберігаються у файлі `public/products.json` та завантажуються асинхронно через `fetch` під час монтування (`onMounted`).
2. **Реактивна фільтрація та пошук (`computed`):** працюють миттєво без перезавантаження сторінки:
   - Розбивка на **9 категорій** з кастомними векторними SVG-іконками («Усі», «Ноутбуки», «Смартфони», «Планшети», «Аудіо», «Смарт-годинники», «Монітори», «Периферія», «Аксесуари») та випадаюче мега-меню **«Каталог»**.
   - **Бічна панель фільтрів (у стилі Rozetka):** фільтрація за діапазоном ціни (`від - до` + кнопка `ОК`), мульти-вибір брендів із підрахунком кількості товарів, перемикачі «Акційні пропозиції» та «Тільки в наявності», а також динамічні технічні фільтри залежно від обраної категорії (обсяг накопичувача, ОЗП, діагональ екрана, лінійка процесора, частота оновлення, тип підключення тощо).
   - **Живий пошук** за назвою, брендом, артикулом (кодом товару) та описом.
3. **Функціонал кошика:** додавання товарів з каталогу або зі сторінки товару, зміна кількості (`+ / -`), видалення окремих позицій та повне очищення кошика. Лічильник товарів і підсумкова сума в шапці оновлюються реактивно.
4. **Компонентна архітектура (Props & Emits):**
   - `AppHeader.vue` - шапка сайту з SVG-логотипом, кнопкою каталогу, живим пошуком та індикатором кошика.
   - `CategoryIcon.vue` - набір кастомних векторних SVG-іконок категорій в єдиному стилі.
   - `CatalogSidebar.vue` - бічна панель фільтрів за ціною, брендами та технічними характеристиками (з підтримкою мобільної виїзної панелі).
   - `ProductCard.vue` - картка товару в сітці каталогу (`props: ['product']`, події `add-to-cart`, `open-product`, `open-reviews`, `select-brand`).
   - `ProductPage.vue` - окрема сторінка товару з інтерактивною фотогалереєю, мініатюрами, повноекранним переглядом фото (Lightbox), таблицею характеристик, блоком відгуків із можливістю написати власний відгук (оцінка 1-5 зірок, ім'я та коментар зі збереженням у `localStorage` і автоматичним перерахунком рейтингу) та схожими товарами.
   - `InfoPage.vue` - інформаційні сторінки магазину («Доставка і оплата», «Гарантія та повернення», «Політика конфіденційності», «Договір публічної оферти», «Про магазин та контакти»).
   - `CartDrawer.vue` - виїзна панель кошика з розрахунком суми, промокодами та списком позицій.
   - `CartItem.vue` - окремий рядок товару в кошику (`props: ['item']`, події `update-quantity`, `remove-item`).
   - `OrderModal.vue` - модальне вікно оформлення замовлення з валідацією форми.
   - `EmptyState.vue` - компонент порожнього стану для кошика та відсутності результатів фільтрації.
   - `Toast.vue` - спливаючі повідомлення про дії користувача.
5. **Синхронізація з `localStorage`:** автоматичне збереження та відновлення вмісту кошика після оновлення сторінки через глибокий спостерігач `watch(cart, ..., { deep: true })`.
6. **Окремі повідомлення про порожні стани:** інформативні блоки для порожнього кошика та для стану «Товарів не знайдено» зі швидким скиданням фільтрів.
7. **Адаптивна верстка та плавні анімації:** коректне відображення на десктопах, планшетах і смартфонах без горизонтальної прокрутки, окремий мобільний банер акції, мобільна панель фільтрів та плавні переходи `<Transition>` / `<TransitionGroup>`.

### Додаткові можливості (бонуси):
- **Маршрутизація через URL-хеш:** кожен товар (`#/product/1`), категорія (`#/category/Ноутбуки`), бренд (`#/brand/Apple`) та інформаційна сторінка (`#/page/delivery`) мають власне пряме посилання.
- **Сортування каталогу:** за популярністю, від дешевих до дорогих, від дорогих до дешевих, за рейтингом, за назвою (А-Я).
- **Акційний банер та система промокодів:**
  - `2027` - новорічна знижка 25% (також активується кліком по святковому постеру)
  - `STUDENT10` - знижка 10%
  - `KPI10` - знижка 10%
  - `VUE20` - знижка 20%
  - `PROMO500` - знижка 500 ₴
- **Оформлення замовлення з перевіркою полів:** валідація ПІБ, українського номера телефону, міста/відділення доставки, вибір способу оплати та генерація номера замовлення.

## Як запустити проєкт локально

### 1. Встановлення залежностей:
```bash
npm install
```

### 2. Запуск локального сервера розробки:
```bash
npm run dev
```
Після запуску відкрийте у браузері посилання `http://localhost:5173/`.

### 3. Збірка для продакшну:
```bash
npm run build
```

### 4. Попередній перегляд зібраного проєкту:
```bash
npm run preview
```
